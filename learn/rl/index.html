SpireZero · learn/rl

Learning reinforcement learning, through the fight you already know

Four weeks, one day at a time, 30 to 60 minutes each: a page with an idea and a toy to click, then a Python exercise with tests. The toys run on a mini fight in JavaScript; the exercises run on SpireZero's real Act 1 fights from day 1 and train PPO on them by day 10. Week 3 turns that trainer into experiments: evaluation, features, reward design. Week 4 moves to whole runs and ends with a capstone that trains and measures an agent in minutes.

Setup, once
learn/rl/setup.sh                                  # .venv with numpy, pytest, CUDA torch; builds target/ffi/libsts2_ffi.so
.venv/bin/python -m pytest learn/rl/exercises/week1/test_day1.py

Each exercise file has TODOs and a docstring per function that the tests check; learn/rl/exercises/solutions/ has the reference answers, and RL_SOLUTIONS=1 runs the tests against them. Rebuild the library (cargo build --profile ffi -p sts2-ffi) after any change to the engine. Progress on this page is saved in this browser.

The repo alongside

  • python/sts2/env.py: Sts2Envs (the batch the exercises use), Sts2PufferEnv (the same with PufferLib's interface and the +1/−1 reward), Sts2RunEnvs (whole runs, week 4).
  • crates/sts2-rl/src/obs.rs and crates/sts2-rl/src/action.rs: the 972-byte observation and the 140-index action space the exercises decode by hand on day 2.
  • crates/sts2-rl/vocab/: the id → name lists (cards, encounters, monsters, powers) behind every embedding table.
