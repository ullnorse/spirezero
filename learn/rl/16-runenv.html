Week 4 · Day 16

The run env

A fight is thirty decisions and a signal at the end. A run is a few hundred decisions of three kinds, map, rewards and shops, with fights in between, and the signal is how far you got. Sts2RunEnvs makes a whole run one episode; combat="greedy" lets the engine's planner play the fights so the agent sees only the run-level choices.

The idea

Same loop, different unit. The observation grows to 2,996 bytes with a phase byte that says which decision is pending; the action space grows to 355 indices, the 140 combat ones followed by the run-level blocks; a step is one agent decision, and decisions with one option are taken inside the env. Everything from weeks 1 to 3 applies unchanged, including the baselines before any training.

One episode, many phases

from sts2 import Sts2RunEnvs
envs = Sts2RunEnvs(64, seed_range=(0, 1000), cycle=True, combat="greedy", character="Necrobinder", threads=4)
phase = envs.obs[:, 3]            # 2 map, 4 rewards, 7 rest, 9 shop, ... (PHASES in the exercise)
legal = envs.legal()              # 64 × 355; bits below 140 only during a fight the agent plays
envs.step(actions); envs.done; envs.won; envs.end; envs.floor

The header (32 bytes) carries floor, HP, gold, deck size, relic count and the map position; the deck, relics, belt, the map's points and whatever screen is pending follow at fixed offsets. The exercise decodes the header and the action index; day 17 featurises the rest.

Baselines by floor

No run-level agent wins at this point: the engine ports Act 1 and a little beyond, and greedy-fought runs die around floor 12. So the number is the final floor, from envs.floor when a run ends, and the protocol is day 13's with floors in place of wins: a fixed seed range, cycled, so two agents play the same runs.

Toy · four rules, 400 runs each

Necrobelt, ascension 0, greedy fights, seeds 0 to 1,000. Standard errors about 0.25.

Random run-level play reaches floor 12.2. Playing the lowest legal index, which means the first map column, claim everything, take the first card of every reward and rest rather than smith, reaches 14.9. Skipping every card reward reaches 10.7: a starter deck does not carry Act 1. The gap between random and a trivial rule is the room a learned agent has to show it learned something; the gap to the top of Act 1 is the room for everything after that.

Where this lives in SpireZero
  • crates/sts2-rl/src/run_obs.rs: the observation, section by section, with every offset; crates/sts2-rl/src/run_action.rs: the index blocks after 140.
  • crates/sts2-rl/src/run_envs.rs: automatic single-option decisions, the resolvers, refused actions (an action the engine would reject has no bit), RunEnd (died, victory, unsupported, stuck, capped at 60,000 actions).
  • crates/sts2-rl/src/resolve.rs: the greedy resolver, a beam search over play sequences each turn, the same policy as cargo xtask sweep --policy greedy.
  • python/tests/test_run_smoke.py: the smallest driver of the run env, including the phase-byte check the exercise repeats.
