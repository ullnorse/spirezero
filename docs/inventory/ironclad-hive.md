### Tier rule

Computed from the extracted fields only (`choice` = any `CardSelectCmd`/`RelicSelectCmd` command; `osty` = any `OstyCmd` command or a mention of Osty; `hooks` counts include inherited ones).

* card: **hard** if choice or osty; **medium** if Power card, any `PowerCmd`, any hook override or a Doom/Soul mention; else **simple**.
* monster: **hard** if it has a `RandomBranchState`/`ConditionalBranchState`, uses rng, adds creatures (`CreatureCmd.Add`), involves Osty or overrides 3+ hooks; **medium** if it applies powers, overrides a hook or moves cards; else **simple**.
* encounter: **hard** if it uses rng (random composition); **medium** if it references more than 3 entities; else **simple**.
* event: **hard** if choice, osty, rng or 3+ hooks; else **medium** (every event has a decision point).
* relic, potion, power, enchantment, affliction: **hard** if choice, osty, 4+ hooks, or rng together with a hook; **medium** if any hook, `PowerCmd`, rng or 2+ distinct commands; else **simple**.
