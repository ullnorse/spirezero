# Semantics: run layer, map, room flow, rewards

Append-only. One fact per bullet, with a decomp reference (`ref/<path>:<line>`) and the task id that found it. Index: `docs/semantics.md`.

## Run layer (R4)
Full detail in `docs/specs/run-layer.md`. Paths are under `ref/decomp/MegaCrit.Sts2.Core.`.
- Run start order: `Player.CreateForNewRun` (starter deck and relic added silently, no `AfterObtained`) → `RunState.CreateForNewRun` (12 run streams and player streams created, no draws) → `InitializeNewRun` (shared and player relic bags shuffled on `UpFront`) → `GenerateRooms` (shared-ancient shuffle, 2 act-count `NextInt`, then each act's events/encounters/boss/ancient on `UpFront`) → `FinalizeStartingRelics` → `EnterAct(0)` (map) → Neow. (R4) `Runs/RunManager.cs:295-312,520-536,725-767,1321-1350`, `Nodes/NGame.cs:1179-1190`
- The map rng is a separate `new Rng(seed, "act_1_map")`, not a `RunRngSet` stream. Rest and unknown counts (`NextGaussianInt`) are drawn before any path. Pruning, `Center/Spread/Straighten` change the final `MapCoord`s that feed monster and encounter rngs. (R4) `Map/StandardActMap.cs:87-114`, `Map/MapPostProcessing.cs`, `Combat/CombatState.cs:245`
- Neow's room counts as a visited Event, so `eventsVisited` is 1 before the first `?` event is picked. (R4) `Runs/RunManager.cs:1206-1209`, `Rooms/RoomSet.cs:88-125`
- Neow options use the event rng `runSeed + slot + xxh64("NEOW")`: one curse `NextItem`, 3 `NextBool`, one `UnstableShuffle`; shown as 2 positive + 1 curse. In single player MassiveScroll is always filtered out. (R4) `Models/EventModel.cs:234`, `Models.Events/Neow.cs:217-286`
- Card reward: potion roll (f32 pity, 0.4 ± 0.1) → gold → potion pick → 3 × (rarity f32, pool pick, upgrade `NextFloat`) on the player's `rewards` rng; the upgrade draw is consumed even when the odds are 0 (Act 1). Pity offset `-0.05f`, `+0.01f` per non-rare, cap 0.4, reset on rare; the boss reward always rolls Rare. (R4) `Odds/CardRarityOdds.cs:69-111`, `Odds/PotionRewardOdds.cs:54-72`, `Factories/CardFactory.cs:214-305`, `Rewards/RewardsSet.cs:206-246`
- The shop draws card rarity and the upgrade check on the player's **`rewards`** rng but item picks and prices on **`shops`**; two relic rarities are rolled (on `rewards`) before any relic is pulled. Prices are `round(base × NextFloat(lo, hi))` in f32. (R4) `Entities.Merchant/MerchantInventory.cs:98-148`, `Factories/CardFactory.cs:40-80`
- `?` rooms are an f32 roll on `UnknownMapPoint` (Monster 0.1, Treasure 0.02, Shop 0.03, rest Event; Elite is −1 and never rolls); the rolled type resets, others add their base. Shop is banned after a shop or before all-shop children. (R4) `Odds/UnknownMapPointOdds.cs:123-177`, `Runs/RunManager.cs:660-668`
- Rest-site Heal is `Heal(MaxHp × 0.3m)` and HP becomes `(int)Math.Min(hp + amount, max)`, which truncates (66 max HP heals 19). One option per visit unless MiniatureTent. (R4) `Entities.RestSite/HealRestSiteOption.cs:90-93`, `Entities.Creatures/Creature.cs:478-492`, `Multiplayer.Game/RestSiteSynchronizer.cs:199-218`
- Referee: `dump_state` outside combat returns only seed/act/floor; sts2-cli's `HealBetweenActs` on `proceed` after a boss is its own approximation (the game heals at the next act's Ancient event). `UnlockState.all` has `NumberOfRuns = 999999999`, so first-run overrides are off. (R4) `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:2268-2287`, `Unlocks/UnlockState.cs:34`
- Referee run mode (T6): `dump_run` traces the run after every action; `Rng` counters are read through `ToSerializable().counter`. The unlock state is confirmed `UnlockState.all` with `NumberOfRuns = 999999999` (`dump_run` prints it on step 0). `HealBetweenActs` is disabled in the vendored sts2-cli. sts2-cli auto-claims gold/relic/potion rewards, auto-picks treasure relic 0 and does not enter combats started by an event (`EnterCombatWithoutExitingEvent`, e.g. Dense Vegetation REST), so those paths are not oracles. A `?` node can roll Treasure at the first unknown (seed `T6S0`, floor 4). (T6) `referee/README.md`, `referee/tracer/RunDump.cs`, `Models/EventModel.cs:556-586`, `Models.Events/DenseVegetation.cs:104`
## Act 1 map generation (RL1)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`. Ported in `crates/sts2-core/src/run/map.rs`; `tools/diff_map.sh 200` matches the referee's `run.map` on seeds `RL1S0..199` (all nodes, types, edges, start, boss).
- The map reads only the seed: it uses `new Rng(seed, "act_1_map")`, which nothing has drawn from when `GenerateMap` runs, and it never reads `UnlockState` (`NumberOfRuns` is not consulted anywhere in `Map/`). Run init therefore adds no map-stream draws; the first draws are the two `NextGaussianInt` calls (rests, then unknowns). (RL1) `Map/StandardActMap.cs:87-114`, `Models.Acts/Overgrowth.cs:134-139`
- `HashSet<MapPoint>` parent/child sets enumerate in insertion order minus removals in this code (no `Add` follows a `Remove`), and the final map matched 200 seeds with insertion-ordered `Vec`s, which confirms the earlier UNVERIFIED note. (RL1) `Map/MapPoint.cs:52-62`, `Map/MapPathPruning.cs`
- The start point `(3,0)` is outside the grid (row 0 is never filled), so `MapPathPruning.IsRemoved(start)` is always true, and `IsInMap` only accepts it through its `Ancient` type. Boss/start also take part in `MapPostProcessing`: `GetAllowedPositions` keeps row-1 and row-15 nodes within one column of the start/boss at column 3. (RL1) `Map/MapPathPruning.cs:333-345`, `Map/MapPostProcessing.cs:177-189`
- `StableShuffle` on map points sorts by `MapPoint.CompareTo` (`MapCoord`: column, then row), which has no ties, so the sort never affects the result beyond making the order canonical. (RL1) `Map/MapPoint.cs:35-42`, `Map/MapCoord.cs:63-66`
- `Rng.NextGaussianInt` is ported on the host libm (`ln`, `sin`, `sqrt`): 200 seeds' rest and unknown counts matched the game on this host. (RL1) `Random/Rng.cs:260-281`
- Not ported (off at ascension 0 / single player): SwarmingElites (8 elites), multiplayer (14 rooms), `StartedWithNeow == false` (start becomes a Monster), second boss, `replaceTreasureWithElites`. (RL1) `Map/MapPointTypeCounts.cs:14`, `Runs/RunManager.cs:820-826`

## Run state and room flow (RL2)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`.
- `GenerateRooms` rolls the rooms of all three default acts (Overgrowth, Hive, Glory from `ActModel.GetDefaultList`) on `UpFront` at run start, so `UpFront` after init depends on Hive's and Glory's event and encounter lists too. With the relic bags (112 + 118 draws) it ends at 417 on seed `T6S0`, matching the referee. (RL2) `Runs/RunManager.cs:743-767`, `Models.Acts/Hive.cs`, `Models.Acts/Glory.cs`
- The shared relic bag's `Populate(relics, rng)` keeps every rarity: `SharedRelicPool` has `FresnelLens` (Event) and `LoomingFruit`, `VeryHotCocoa` (Ancient), so it shuffles six buckets in first-seen order (Uncommon, Common, Rare, Shop, Event, Ancient). The player bag's `Populate(player, rng)` keeps only Common/Uncommon/Rare/Shop (Necrobinder's starter `BoundPhylactery` is dropped). (RL2) `Runs/RelicGrabBag.cs:56-100`, `Models.RelicPools/SharedRelicPool.cs`
- `GrabBag.GrabAndRemove(rng, predicate)` makes no draw when no entry satisfies the predicate, otherwise redraws `NextDouble() * totalWeight` (f64) until the drawn entry does. (RL2) `Helpers/GrabBag.cs`
- After a room is finished (Neow option chosen, card reward skipped) the referee is in a `MapRoom` (`room_type` `Map`) and `coord` stays the last visited point. When the player dies the decision is `game_over`, `hp` is 0 and the room stays the `CombatRoom`. (RL2, observed)
- Neow options whose effects are ported: `LavaRock` (only `TryModifyRewards` on the Act 1 boss) and `StoneHumidifier` (only `AfterRestSiteHeal`) do nothing until those rooms; `GoldenPearl` is `GainGold(150)`; `NutritiousOyster` is `GainMaxHp(11)` (`SetMaxHp` then `Heal` by the gained amount). On seeds `RL2S0..29`, 21 of 30 Neows offer none of these. (RL2) `Models.Relics/LavaRock.cs`, `Models.Relics/StoneHumidifier.cs`, `Models.Relics/GoldenPearl.cs`, `Models.Relics/NutritiousOyster.cs`, `Commands/CreatureCmd.cs:838-851`
- A natural row-1 fight has `TotalFloor` 2 and `CurrentMapCoord` = the chosen point; the referee's streams and monster HP match the engine's combat built with those (seed `RL2S4`). (RL2) `Runs/RunManager.cs:876-938`, `Combat/CombatState.cs:245`

## Rewards, rest site, treasure, `?` rooms, Neow options (RL3)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`. Ported in `crates/sts2-core/src/run/{rewards,odds,potions,relics,cards}.rs`; `tools/diff_run.sh` compares gold, potions, odds and both stream sets.
- Seed `T6S0` after Phial Holster: the first monster fight's rewards are gold 10, `HEART_OF_IRON`, cards `DEFY, ...`, with 13 `rewards` draws and the pity offset at `-0.02` (potion roll, gold `NextInt(10, 21)`, potion rarity + pick, 3 × (rarity, pick, upgrade `NextFloat`)), matching the referee. (RL3) `Rewards/RewardsSet.cs:125-147,206-246`, `Factories/CardFactory.cs:89-109,214-305`
- `PotionFactory.GetPotionOptions` is the character pool first (`Necrobinder4Epoch.Potions`: PotionOfDoom, PotOfGhouls, BoneBrew), then `SharedPotionPool` in declaration order (45). A picked potion leaves the working list. `PhialHolster` draws its 2 potions the same way on the run's `CombatPotionGeneration` (4 draws on `T6S0`) after adding one slot. (RL3) `Factories/PotionFactory.cs:45-90`, `Models.Relics/PhialHolster.cs`
- A potion reward that does not fit stays on the screen (`TryToProcure` fails with `TooFull`); procuring fills the first empty slot. (RL3) `Rewards/PotionReward.cs:76-93`, `Entities.Players/Player.cs:628-660`
- Of the pool potions only `FairyInABottle` has listener hooks (`ShouldDie`, `AfterPreventingDeath`); every other potion acts only through `OnUse`, so an unported potion can sit in the belt through a fight. (RL3) `docs/inventory/act1.json`
- A treasure room rolls its relic rarity on `TreasureRoomRelics` and pulls from the **shared** bag, which loses it at once; the player's bag loses it only on `RelicCmd.Obtain`. Gold is `rewards.NextInt(42, 53)`. Both are skipped while `ShouldGenerateTreasure` is false (`SilverCrucible`: its first treasure room, counted by `AfterRoomEntered` before the roll). (RL3) `Multiplayer.Game/TreasureRoomRelicSynchronizer.cs:89-111`, `Multiplayer.Game/OneOffSynchronizer.cs:128-143`, `Rooms/TreasureRoom.cs`, `Models.Relics/SilverCrucible.cs`
- `PullNextRelicFromFront` (elite and `SmallCapsule` relic rewards) rolls on the player's `rewards`, pulls from the player's bag and removes the relic from the shared bag. `PullFromFront` falls through Shop → Common → Uncommon → Rare when a bucket is empty, then `Circlet`. Every pool relic's `IsAllowed` override holds before the Act 3 treasure (`TotalFloor < 41`); see the C5 entry below for the cull. (RL3) `Factories/RelicFactory.cs:13-41`, `Runs/RelicGrabBag.cs:120-139,218-243`, `Models/RelicModel.cs:452-456`
- `FromDeckForUpgrade` lists the upgradable deck cards in deck order. `FromDeckForRemoval` lists removable cards (`IsRemovable` = not `Eternal`), with curses first and then deck order. With `MinSelect == MaxSelect` there is no manual confirmation, so a list no longer than `MinSelect` is taken without a prompt; Smith sets `RequireManualConfirmation` and `Cancelable`. (RL3) `Commands/CardSelectCmd.cs:537-560,739-800`, `CardSelection/CardSelectorPrefs.cs:62-77`, `Entities.RestSite/SmithRestSiteOption.cs:49-74`
- Neow relic effects: `NeowsTalisman` upgrades the **last** Basic Strike and the last Basic Defend. `Pomander` upgrades 1 chosen card. `PreciseScissors` removes 1 chosen card; `PrecariousShears` removes 2, then deals 16 unblocked damage. `ArcaneScroll` adds 1 uniform rare (`CreateForReward`, `NoUpgradeRoll`, no choice) on `rewards`. `SmallCapsule` gives a `RelicReward`. `StoneHumidifier` does `GainMaxHp(5)` after a rest-site heal. `FishingRod` upgrades a random upgradable card on `Niche` every third monster combat (`AfterCombatEnd`). `SilverCrucible` upgrades every card of the first 3 card rewards (`IsCardReward` only). `BoomingConch` acts only in elite rooms. `LavaRock` adds 2 relic rewards after the Act 1 boss. (RL3) `Models.Relics/*.cs`
- `Strawberry`, `Pear`, `Mango` (`GainMaxHp` 7/10/14), `LeesWaffle` (`GainMaxHp(7)`, then heal to full), `OldCoin` (+300 gold) and `PotionBelt` (+2 slots) only have `AfterObtained`. (RL3) `Models.Relics/*.cs`
- The `?` blacklist reads the previous history entry and the **destination's** children: `EnterMapCoord` adds the coord to the visited list before `EnterMapPointInternal` builds the blacklist. (RL3) `Runs/RunManager.cs:660-668,906-916`

## Events (RL4)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`. Ported in `crates/sts2-core/src/run/events.rs` and `content/events/`; `tools/diff_run.sh 50` enters 22 event rooms and matches all (200 seeds: 59 rooms).
- `CreateRoom` pulls the event (`PullNextEvent`: `IsAllowed` and `VisitedEventIds` checked from `events[eventsVisited % n]`, each skip `eventsVisited++`, then `AddVisitedEvent`) before the history entry is appended, so `IsAllowed` sees `TotalFloor` without the new point; `MarkRoomVisited(Event)` adds 1 after the room is entered. `T6S0`'s first `?` event skips `WarHistorianRepy` (never allowed) and ends at `events_visited` 3. (RL4) `Runs/RunManager.cs:958-992`, `Models/ActModel.cs:437-443`, `Rooms/RoomSet.cs:110-125`
- An event's `Rng` is `runSeed + (IsShared ? 0 : slot) + xxh64(Id.Entry)`, the same as Neow's in single player; nothing the run traces reads it. (RL4) `Models/EventModel.cs:234`
- `PlayerCmd.GainGold(decimal)` adds `(int)amount` (truncated) only if `amount > 0`; `LoseGold` floors at 0. `JungleMazeAdventure`'s gold is `150m + (decimal)NextFloat(-15f, 15f)`, and `(decimal)float` rounds to 7 significant digits (`DecCalc.VarDecFromR4`), which can carry into the integer part before the `(int)`. (RL4) `Commands/PlayerCmd.cs:140-205`, `Models.Events/JungleMazeAdventure.cs`
- `CreatureCmd.LoseMaxHp` deals the HP above the new max as unblockable damage, then sets max HP to `max(1, max - amount)`. (RL4) `Commands/CreatureCmd.cs:863-879`
- Draw-pile choices are shown ordered by rarity, then id (`CardSelectCmd.FromCombatPile`), so a draw-pile card choice's indices refer to that order. (RL4) `Commands/CardSelectCmd.cs:489-494`
- `CardReward(options, ...)` adds `IsCardReward`, so `SilverCrucible` upgrades event card rewards (`BrainLeech` RIP, `TheFutureOfPotions`) but not grid picks (`SelectCardsToAddToDeckFromGrid` uses `CreateForReward` directly). `ForNonCombatWithDefaultOdds` is `RegularEncounter` base odds (no pity change) with `NoUpgradeRoll`; `ForNonCombatWithUniformOdds` skips the rarity roll. (RL4) `Rewards/CardReward.cs:114`, `Runs/CardCreationOptions.cs`, `Factories/CardFactory.cs:214-243`
- `TheFutureOfPotions` rolls a card type on the event `Rng` for every held potion (not only the three offered) when the first option is built. (RL4) `Models.Events/TheFutureOfPotions.cs`
- `IsTransformable` is `IsRemovable` (not `Eternal`) for a deck card; `ForbiddenGrimoire` (Necrobinder pool) is `Eternal`. (RL4) `Models/CardModel.cs:738-751`, `Models.Cards/ForbiddenGrimoire.cs`

## Run-level hooks, deck commands, event fights (RL5)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`. Ported in `crates/sts2-core/src/run/{hooks,ctx,state,rewards}.rs` and the relic files.
- Outside combat `IterateHookListeners(null)` lists the deck cards (each followed by its enchantment), then the relics (not melted), the potions, the modifiers and badges; in combat the combat's own listeners follow. (RL5) `Runs/RunState.cs:545-595`
- `GenerateWithoutOffering` populates the room's rewards in list order, then runs `ModifyRewards` (`TryModifyRewards`, then `Late`), then populates the rewards the listeners added, in order, then `AfterModifyingRewards` for the modifiers, then sorts by `RewardsSetIndex`. `new GoldReward(amount)` is populated at construction (no draw); `PrayerWheel`/`WhiteStar` add `CardReward(ForRoom(Monster/Boss), 3)`, an `Encounter` source that moves the pity. `OfferCustom` builds a set with `Room == null`. (RL5) `Rewards/RewardsSet.cs:125-147`, `Rewards/GoldReward.cs`, `Runs/CardCreationOptions.cs:79-107`, `Commands/RewardsCmd.cs:47-50`
- `ShouldForcePotionReward` is read before the potion roll; a forced potion returns before the `NextFloat` and leaves the odds unchanged. (RL5) `Odds/PotionRewardOdds.cs:54-72`
- `CreateForReward` calls `ModifyCardRewardCreationOptions` once per card, but checks `NoUpgradeRoll` and passes `TryModifyCardRewardOptions` the caller's (unmodified) options. (RL5) `Factories/CardFactory.cs:89-109,214-216`
- `PlayerCmd.GainGold` runs `ModifyGoldGained` and `AfterModifyingGoldGained` before the `amount > 0` check; `GoldReward.OnSelect`, the treasure gold, `GoldenPearl` and `OldCoin` all go through it, so `DragonFruit`'s `AfterGoldGained` fires on each. `BowlerHat` multiplies by `1.25m` before the `(int)` cast. (RL5) `Commands/PlayerCmd.cs:140-177`, `Rewards/GoldReward.cs:75-79`, `Multiplayer.Game/OneOffSynchronizer.cs:139`
- A `?` roll's allowed set is the four odds keys plus Event, minus the blacklist, then `ModifyUnknownMapPointRoomTypes`; a type removed there neither rolls nor has its odds grow (`JuzuBracelet` freezes the monster odds). The default is Event if allowed, else the lowest allowed `RoomType`. (RL5) `Odds/UnknownMapPointOdds.cs:137-177`, `Models.Relics/JuzuBracelet.cs`
- `AfterRoomEntered` fires in a rest site after its options are generated, in a treasure room before the chest (`ShouldGenerateTreasure`), and in an event room after `BeginEvent`. (RL5) `Rooms/RestSiteRoom.cs:31-37`, `Rooms/TreasureRoom.cs:40-47`, `Rooms/EventRoom.cs:56-88`
- `TransformToRandom` on a deck card draws one `NextItem` from the original's pool (`ColorlessCardPool` for a Quest, Event, Ancient or Token card), Common/Uncommon/Rare only unless the original is a Status or Curse, without the original's id and multiplayer-only cards; the replacement is a fresh, unupgraded card that goes through `ModifyCardBeingAddedToDeck` and joins the end of the deck (no `BeforeCardRemoved`). A curse transforms within `CurseCardPool`. (RL5) `Factories/CardFactory.cs:170-208`, `Commands/CardCmd.cs:374-460`, `Entities.Cards/CardTransformation.cs`
- `FromDeckForTransformation` lists non-Quest transformable cards in deck order; `FromDeckForRemoval` sorts removable cards with curses first (`-999999999`), then by deck index; sts2-cli's `select_cards` returns the picked cards in the order given. (RL5) `Commands/CardSelectCmd.cs:589-600,739-760`, `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:4599-4606`
- `CardCmd.Enchant` throws unless `CanEnchant`, which refuses a second enchantment unless it is stackable and the same kind; a stackable one adds `(int)amount`. `CardCmd.Downgrade` keeps the enchantment. (RL5) `Commands/CardCmd.cs:208-223,536-563`
- `RelicCmd.Replace` removes the original, then obtains the replacement at the original's index (`AfterObtained` runs). (RL5) `Commands/RelicCmd.cs:62-71`
- An event fight (`EnterCombatWithoutExitingEvent`) is a `CombatRoom` pushed on the event's room: it is added to the map point's history entry (no new floor), `MarkRoomVisited` skips it (room stack deeper than one), and its rewards are the encounter room's own plus `extraRewards`. Leaving them resumes the event if `shouldResumeAfterCombat`, else opens the map. This corrects the content-gaps survey's "no rewards". (RL5) `Models/EventModel.cs:556-586`, `Multiplayer.Game/EventCombatSynchronizer.cs:114-148`, `Runs/RunManager.cs:1199-1208,1255-1283,1398-1414`
- Out of combat a potion's `OnUseWrapper` empties the slot, then runs `BeforePotionUsed`, `OnUse` and `AfterPotionUsed`. sts2-cli's `use_potion` gives an `AnyPlayer` potion no target (only `Self`/`TargetedNoCreature` get the player), so an out-of-combat `FruitJuice` throws and is discarded there: no oracle. (RL5) `Models/PotionModel.cs:297-354`, `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:2051-2120`
- At WearyTraveler (ascension 2+) Neow sets HP to 0 and heals `(MaxHp - 0) × 0.8m`, truncated: 52 of 66. AscendersBane (5+) adds the curse to the deck silently in `ApplyEffectsTo`. (RL5) `Models/AncientEventModel.cs:170-191`, `Entities.Ascension/AscensionManager.cs:50-66`
- sts2-cli presents only the first card reward of a rewards screen and goes to the map once it is answered; a second one (`PrayerWheel`) is dropped. (RL5, observed on `RL2S44`)
- `MiniatureTent` keeps the other rest-site options, but sts2-cli forces the map after Heal and Smith, so it has no oracle (not ported). (RL5) `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:2002-2012`

## Shop (RL6)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`. Ported in `crates/sts2-core/src/run/shop.rs` (prices in `run/odds.rs`); `tools/diff_run.sh` compares the referee's `pending` shop (cards, relics, potions, prices, removal cost).
- The sale entry draws its price twice: `Populate` runs `CalcCost`, then `SetOnSale` runs it again and halves (`/ 2`). So the character cards take 11 `shops` price draws, not 10. (RL6) `Entities.Merchant/MerchantInventory.cs:98-112`, `Entities.Merchant/MerchantCardEntry.cs:111-129`
- The colorless cards have no `GetNextAllowedRarity`: `NextItem` over the unlocked colorless cards of exactly that rarity, minus the stocked cards. A character slot excludes every card already stocked (any type). (RL6) `Factories/CardFactory.cs:40-80`, `Entities.Merchant/MerchantCardEntry.cs:68-99`
- `Mathf.RoundToInt`, `(int)Mathf.Round` and `(int)Math.Round((float)…)` are all half-to-even here: engine prices computed as `f32` products rounded with `round_ties_even` matched every shop on `RL2S0..49` (colorless base `RoundToInt(150 × 1.15f) = 172`, `RoundToInt(75 × 1.15f) = 86`). (RL6) `Entities.Merchant/MerchantCardEntry.cs:38-51`, `Entities.Merchant/MerchantRelicEntry.cs:42-45`
- Relic slots pull with `PullFromBack`: the **last** relic of the bucket passing `IsAllowedInShops` (false for `AmethystAubergine`, `TheCourier`, `LuckyFysh`, `OldCoin`, `BowlerHat`), falling through Shop → Common → Uncommon → Rare; the relic leaves both bags at once. `MerchantCost` is by the relic's own rarity (175/225/275/200; `Circlet` is `None`: 1). (RL6) `Runs/RelicGrabBag.cs:156-173,218-243`, `Factories/RelicFactory.cs:73-78`, `Models/RelicModel.cs:304-315`
- Merchant potion prices are randomized only when `TestMode.IsOff`; sts2-cli sets `TestMode.IsOn = true`, so the referee shows base prices (50/75/100) and makes 3 fewer `shops` draws per shop. The engine models this with `Run::in_test_mode` (the diff session uses it). No other ported rule reads `TestMode`. (RL6) `Entities.Merchant/MerchantPotionEntry.cs:60-70`, `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:4163`
- `MerchantEntry.Cost` is `(int)Hook.ModifyMerchantPrice(_cost)` inside a `MerchantRoom`: `MembershipCard` ×`0.5m`, `TheCourier` ×`0.8m`, truncated after folding. A card is added to the deck before `LoseGold(Cost)`; a relic pays, then `RelicCmd.Obtain`; a potion `TryToProcure`s (fails on a full belt), then pays. `TheCourier` refills a bought slot (`ShouldRefillMerchantEntry`): a card slot `Populate`s again while the bought card still counts as stocked (off sale), a relic slot rolls a rarity on `rewards` and pulls with the shelf as blacklist, a potion slot draws one potion on `shops` without a blacklist. (RL6) `Entities.Merchant/*.cs`, `Models.Relics/MembershipCard.cs`, `Models.Relics/TheCourier.cs`
- Card removal: `FromDeckForRemoval` with one pick, `Cancelable` and `RequireManualConfirmation`; on a pick `LoseGold(cost)`, `RemoveFromDeck`, then `ExtraFields.CardShopRemovalsUsed++`. The cost `75 + 25 × CardShopRemovalsUsed` is fixed when the shop is generated.
