# Semantics: potions and relics

Append-only. One fact per bullet, with a decomp reference (`ref/<path>:<line>`) and the task id that found it. Index: `docs/semantics.md`.

## Potions and UI API (C3)
- The belt is a fixed list of slots (`Player.initialMaxPotionSlotCount = 3`, one fewer from `AscensionLevel.TightBelt` = 4). Using or discarding a potion sets its slot to `null`; the other potions keep their slots. (C3) `Entities.Players/Player.cs:28,585-606,692-706`, `Entities.Ascension/AscensionManager.cs:56-59`
- `OnUseWrapper`: `RemoveBeforeUse` (slot emptied) -> `Hook.BeforePotionUsed` -> effect depth++ -> `OnUse` -> depth-- -> only if the owner is alive: `History.PotionUsed`, `Hook.AfterPotionUsed`, `CheckForEmptyHand`. Both hooks iterate `runState.IterateHookListeners(combatState)`, unguarded. The executor then runs `CheckWinCondition`. (C3) `Models/PotionModel.cs:297-354`, `Hooks/Hook.cs:996-1015`
- `IsValidTarget`: a null target is valid only for non-single-target types (or `TargetedNoCreature`); otherwise the target must be alive, and `AnyEnemy` = other side, `AnyPlayer` = `IsPlayer` (never Osty), `Self` = the owner. `EnqueueManualUse` replaces a null target with the owner when the owner is valid. The use button needs a living owner and `Usage` `CombatOnly`/`AnyTime` (`Automatic` never). (C3) `Models/PotionModel.cs:242-295`, `Nodes.Potions/NPotionPopup.cs:207-260`
- `FirePotion`: 20 damage, `ValueProp.Unpowered` (so Strength/Shrink do not apply), dealer the owner, no card. `BlockPotion`: 12 block, `Unpowered`, `AnyPlayer`. `EnergyPotion`: `PlayerCmd.GainEnergy(2)`, `AnyPlayer`. All three are `CombatOnly`. (C3) `Models.Potions/{FirePotion,BlockPotion,EnergyPotion}.cs`
- `PlayerCmd.GainEnergy`: nothing for `amount <= 0` or while `IsEnding`; else `ModifyEnergyGain`, then `Energy = (int)clamp(Energy + x, 0, 999999999)`. (C3) `Commands/PlayerCmd.cs:29-42`, `Entities.Players/PlayerCombatState.cs:181-188`
- Potions are combat listeners after the player's relics, by slot (`CombatState.cs:437`); a used potion has already left its slot, so it does not hear its own `Before/AfterPotionUsed`. (C3) `Combat/CombatState.cs:430-445`
- Intent damage (`AttackIntent.GetSingleDamage`): `Hook.ModifyDamage(target = the local player's creature, dealer = the monster, DamageCalc(), ValueProp.Move, no card)`, then `max(0, (int)x)`; evaluated on the current state, not the state mid-move. (C3) `MonsterMoves.Intents/AttackIntent.cs:107-116`
- The referee's `use_potion {potion_index}` indexes `player.Potions` (occupied slots only), not slots; `target_index` is read only for `AnyEnemy` potions (living enemies), `Self` potions get the player and others `null` (so `UsePotionAction` picks the player for `AnyPlayer`). (C3) `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:2039-2085`, `GameActions/UsePotionAction.cs:112-115`
- English titles are in the game's `localization_eng/*.json` (`<ENTRY>.title`); e.g. `DIE_FOR_YOU_POWER` is "Die for You", `STRIKE_NECROBINDER` is "Strike". (C3) `referee/vendor/sts2-cli/localization_eng/`


## Combat potions, batch PT1
- `CardPileCmd.Add(cards, pile)` defaults to the bottom position; `AddGeneratedCardsToCombat` adds card by card (history entry, `Add`, `AfterCardGeneratedForCombat` each), so `Soul.CreateInHand` is "create all, then add each". (PT1) `Commands/CardPileCmd.cs:281-314`, `Models.Cards/Soul.cs:31-53`
- `CardCmd.DiscardAndDraw`: per card `Add(discard)`, `History.CardDiscarded`, `AfterCardDiscarded`; then the draw; Sly cards (decided before the discard) autoplay last. (PT1) `Commands/CardCmd.cs:172-205`
- `FromHand` skips the prompt when the filtered hand is empty, or when `!RequireManualConfirmation && count <= MinSelect`; `GamblersBrew`'s prefs `(prompt, 0, 999999999)` therefore always prompt for a non-empty hand (the engine caps `max` at the hand size). (PT1) `Commands/CardSelectCmd.cs:817-867`
- `SneckoOil`: after the draw, each hand card that does not cost X and whose `GetWithModifiers(None)` is `>= 0` (i.e. has a non-negative base) gets `SetThisTurnOrUntilPlayed(CombatEnergyCosts.NextInt(4))`, in hand order. (PT1) `Models.Potions/SneckoOil.cs:27-52`
- `TouchOfInsanity` filter: `CostsEnergyOrStars(false)` (local cost > 0 or star cost > 0) or `(true)` (global cost > 0 or star cost > 0); the pick is `SetToFreeThisCombat`. `LiquidMemories` picks from the discard pile and `SetToFreeThisTurn`s (this turn or until played); `DropletOfPrecognition` picks from the draw pile with no cost change. (PT1) `Models/CardModel.cs:1267-1277,1579-1595`
- `FairyInABottle`: `ShouldDie` is false only for the owner; `AfterPreventingDeath` runs the full `OnUseWrapper` (slot emptied, `BeforePotionUsed`, `OnUse` = heal `max(MaxHp * 0.3m, 1m)`, `AfterPotionUsed` if alive) with no `CheckWinCondition` of its own. `Usage` is `Automatic` and `CanBeGeneratedInCombat` false. (PT1) `Models.Potions/FairyInABottle.cs`, `Models/PotionModel.cs:297-354`
- `BeetleJuice` applies `ShrinkPower` with the `Repeat` var (4), not `DamageDecrease` (30, description only). `BottledPotential` moves the hand to the bottom of the draw pile, shuffles, then draws 5. `Fortifier` gains `Block * 2` unpowered. (PT1) `Models.Potions/{BeetleJuice,BottledPotential,Fortifier}.cs`

## First combat relics, batch RT1
- Turn-gated relics read `PlayerCombatState.TurnNumber` (1 on the first player turn, +1 per `SwitchSides` back to the player). `Akabeko`, `BagOfMarbles`, `BagOfPreparation`, `Bellows`, `BloodVial` and `FestivePopper` act at `TurnNumber <= 1` (`== 1` for the Popper); `Candelabra` at 2, `CaptainsWheel` and `Chandelier` at 3. `BagOfMarbles` hooks `BeforeSideTurnStart` (before the enemies' `RollMove`), Akabeko/Candelabra/Chandelier `AfterSideTurnStart`, `BloodVial` `AfterPlayerTurnStartLate`. (RT1) `Models.Relics/{Akabeko,BagOfMarbles,BagOfPreparation,Bellows,BloodVial,Candelabra,CaptainsWheel,Chandelier,FestivePopper}.cs`
- `BagOfMarbles` and `FestivePopper` target `CombatState.HittableEnemies`; the Popper's damage is the `DamageVar` unpowered, dealer the owner, no card. `CloakClasp` gains `(int)(hand count * 1m)` unpowered at `BeforeSideTurnEnd` and does nothing for an empty hand. (RT1) `Models.Relics/{BagOfMarbles,FestivePopper,CloakClasp}.cs`
- `Bellows` is `CardCmd.Upgrade(Hand.Cards)`: nothing once combat is ending, skips non-upgradable cards. `ChemicalX.ModifyXValue` adds 2 for every card of the owner (`BeforeCardPlayed` only flashes). `Bookmark` (`AfterFlush`) draws one `NextItem` on `CombatCardSelection` over the retained cards that are not X-cost and whose local cost is above 0 (no draw when the list is empty) and does `AddUntilPlayed(-1)`. (RT1) `Commands/CardCmd.cs:267-300`, `Models.Relics/{ChemicalX,Bookmark}.cs`
- `BoneFlute` fires on every `AfterAttack` whose attacker is Osty with `PetOwner` the owner, once per attack command (not per hit). `BookRepairKnife` (`AfterDiedToDoom`) needs `DoomPower` and a Doom source, neither ported yet. (RT1) `Models.Relics/{BoneFlute,BookRepairKnife}.cs`
## Relic state and combat generation (C9)
Paths are under `ref/decomp/MegaCrit.Sts2.Core.`.
- A relic is one model instance for the whole run, so its private fields outlive each combat as much as its `[SavedProperty]` ones; relics reset per-combat or per-turn counters themselves (`Kunai` in `BeforeSideTurnStart` and `AfterCombatEnd`, `ThrowingAxe` in `AfterRoomEntered` and `AfterCombatEnd`). Only a save and reload drops the unsaved fields. (C9) `Models.Relics/Kunai.cs:90-126`, `Models.Relics/ThrowingAxe.cs:27-61`
- `Nunchaku`: `AfterCardPlayed` counts the owner's Attacks in `[SavedProperty] AttacksPlayed` and, while combat is in progress, gains 1 energy on every multiple of 10; `IsActivating` is display only. (C9) `Models.Relics/Nunchaku.cs`
- `Bread`: `ModifyMaxEnergy` +1 except on turn 1; `AfterSideTurnStart` on turn 1 runs `PlayerCmd.LoseEnergy(2)`, which does nothing for amount <= 0 or while `IsEnding`, else clamps energy to 0..999999999 with no hooks. (C9) `Models.Relics/Bread.cs`, `Commands/PlayerCmd.cs:49-61`, `Entities.Players/PlayerCombatState.cs:172-179`
- `SturdyClamp` vetoes `ShouldClearBlock` for the owner, then `CreatureCmd.LoseBlock(block - 10)`; `LoseBlock` needs combat not over or ending, a living target and a positive amount, does `Block = (int)max(Block - amount, 0)`, and fires `AfterBlockBroken` (unguarded) when that took the last block. (C9) `Models.Relics/SturdyClamp.cs`, `Commands/CreatureCmd.cs:710-722`, `Entities.Creatures/Creature.cs:469-476`
- `CardPileCmd.AutoPlayFromDrawPile`: per card `ShuffleIfNecessary` (draw empty and discard not), take top/bottom (random: `CombatCardSelection`) to the Play pile; then for each taken card, unless the owner is dead, `ExhaustOnNextPlay = forceExhaust` (it overwrites a true) and `CardCmd.AutoPlay(card, null)`. `DistilledChaos` takes 3 from the top. (C9) `Commands/CardPileCmd.cs:1148-1198`, `Models.Potions/DistilledChaos.cs`
- `CardFactory.GetDistinctForCombat`: `FilterForCombat` (`CanBeGeneratedInCombat`, not Basic/Ancient/Event, `Distinct`), then `TakeRandom` = `UnstableShuffle` of the whole list on the given rng (always `CombatCardGeneration` in scope) and `Take(count)`, each created with `CombatState.CreateCard`. Necrobinder pool cards not generated: `Eidolon`, `Transfigure`; Colorless: `Alchemize`, `HandOfGreed`, `HiddenGem`. Canonically Ethereal Necrobinder pool cards: Defile, Defy, Demesne, EnfeeblingTouch, Fear, Lethality, Parse, Seance (BansheesCry, CallOfTheVoid, Pagestorm, SpiritOfAsh, Veilpiercer and SculptingStrike only mention it). `BigHat` on D1S0/D1S1 matches the referee. (C9) `Factories/CardFactory.cs:119-162`, `Extensions/IEnumerableExtensions.cs:17`, `Models.Relics/BigHat.cs`
- `ColorlessCardPool` has 65 cards, 12 of them `MultiplayerOnly` (BeaconOfHope, BelieveInYou, Coordinate, GangUp, HuddleUp, Intercept, Knockdown, Lift, Mimic, Rally, TagTeam, TheBall); with every epoch revealed nothing else is removed. (C9) `Models.CardPools/ColorlessCardPool.cs`, `Models/CardPoolModel.cs:101-114`
- `CardSelectCmd.FromChooseACardScreen` takes at most 3 cards, returns null for none, and asks the selector for 0 to 1 cards whatever `canSkip` (the referee's selector prompts even for one option when min is 0). (C9) `Commands/CardSelectCmd.cs:252-267`, `referee/vendor/sts2-cli/src/Sts2Headless/RunSimulator.cs:4555-4576`

(RT2) `Models.Relics/{IntimidatingHelmet,IvoryTile,GamePiece}.cs`
- `GremlinHorn.AfterDeath` fires for every creature of the other side (energy, then draw); `MercuryHourglass` deals 3 unpowered damage to `HittableEnemies` every player turn start (owner as dealer, no card). `MiniatureCannon.ModifyDamageAdditive` adds 3 for a powered attack from an upgraded card source. - `MummifiedHand.AfterCardPlayed` (Power played): `list` = hand cards with base cost (`GetWithModifiers(None)`) > 0; tries `NextItem` on `CombatCardSelection` over `list` costing energy (global modifiers), then the hand's costing cards, then `list`, then the hand (an empty list draws nothing); the pick is `SetToFreeThisTurn`. (RT2) `Models.Relics/MummifiedHand.cs`
- `LuckyFysh` (`AfterCardChangedPiles`, 15 gold when a card of the owner lands in `PileType.Deck`; `IsAllowed` before the Act 3 treasure) acts only on the run deck, and the run layer has no such hook yet. (RT2) `Models.Relics/LuckyFysh.cs`

## Combat potions, batch PT2
- `PotionOfBinding` reads its two `PowerVar`s crosswise (`WeakPower` gets the `VulnerablePower` var's `IntValue` and the reverse; both are 1), applying Weak to every `HittableEnemies` creature, then Vulnerable. `ShacklingPotion` applies `ShacklingPotionPower` (a negative `TemporaryStrengthPower`) to `HittableEnemies`. (PT2) `Models.Potions/{PotionOfBinding,ShacklingPotion}.cs`
- `FlexPotion` / `SpeedPotion` / `ShacklingPotion` apply `FlexPotionPower` / `SpeedPotionPower` / `ShacklingPotionPower`, which are `TemporaryStrengthPower`/`TemporaryDexterityPower` subclasses: `BeforeApplied` applies the Strength or Dexterity (sign flipped when `IsPositive` is false), `AfterPowerAmountChanged` applies the change, and `AfterSideTurnEnd` (owner in participants) removes the power and applies the opposite amount. Their titles are the potion's. (PT2) `Models.Powers/{TemporaryStrengthPower,TemporaryDexterityPower,FlexPotionPower,SpeedPotionPower,ShacklingPotionPower}.cs`
- `Clarity` (title "Clarity Extract") draws 1, then applies `ClarityPower` 3: `ModifyHandDraw` adds 1 whatever the stack, `AfterSideTurnStart` decrements. `RadiantTincture` gains 1 energy, then `RadiancePower` 3: `AfterEnergyReset` gains 1 energy and decrements. `Duplicator` applies `DuplicationPower` 1 with the target as applier: `ModifyCardPlayCount` +1, `AfterModifyingCardPlayCount` decrements, `AfterSideTurnEnd` removes it. (PT2) `Models.Potions/{Clarity,RadiantTincture,Duplicator}.cs`, `Models.Powers/{Clarity,Radiance,Duplication}Power.cs`
- `ShipInABottle`: `CreatureCmd.GainBlock(target, BlockVar(10, Unpowered), null)`, then `BlockNextTurnPower` 10. `LiquidBronze` = Thorns 3 (damages a dealer of a powered attack, or an `Omnislice` card, with 3 unpowered damage before the hit lands), `LuckyTonic` = Buffer 1 (`ModifyHpLostAfterOstyLate` to 0, `AfterModifyingHpLostAfterOsty` decrements), `MazalethsGift` = Ritual 1 (Strength at the end of the owner's side's turn; skipped once for an enemy owner), `RegenPotion` = Regen 5 (heal `Amount` then decrement at `BeforeSideTurnEndEarly`), `PowderedDemise` = Demise 9 (unblockable unpowered damage to the owner at the end of its side's turn, no dealer), `PotionOfDoom` = Doom 33, `HeartOfIron` = Plating 7, `StableSerum` = RetainHand 2. (PT2) `Models.Potions/*.cs`, `Models.Powers/{Thorns,Buffer,Ritual,Regen,Demise}Power.cs`
- `GigantificationPower`: like Vigor, the first powered Attack card's command is remembered; `ModifyDamageMultiplicative` is 3 for that card's hits (1 for any other card), and `AfterAttack` of that command clears it and decrements. (PT2) `Models.Powers/GigantificationPower.cs`
- `AttackPotion`/`SkillPotion`/`PowerPotion` offer 3 distinct cards of that type from the character pool (`GetDistinctForCombat` on `CombatCardGeneration`) on the choose-a-card screen; the pick is `SetToFreeThisTurn` and added to the hand. `ColorlessPotion` does the same from `ColorlessCardPool`. `OrobicAcid` makes three separate 1-card picks (Attack, Skill, Power) before freeing and adding all three. (PT2) `Models.Potions/{AttackPotion,SkillPotion,PowerPotion,ColorlessPotion,OrobicAcid}.cs`
- `EntropicBrew` (AnyTime): while the belt has an open slot, `PotionFactory.CreateRandomPotionOutOfCombat(player, CombatPotionGeneration)` (one `NextFloat` rarity roll and one `NextItem` per potion, the whole pool every time, restricted potions included) and `PotionCmd.TryToProcure`. The slot of the used brew is empty by then, so it is refilled too. (PT2) `Models.Potions/EntropicBrew.cs`, `Factories/PotionFactory.cs:30-90`
- `Ambergris` (Event rarity, AnyTime): heals `MaxHp * 50 / 100`, and in combat applies `AmbergrisPower`; ported in C14 once the extra-turn loop existed (see `combat-core.md`). (PT2) `Models.Potions/Ambergris.cs`, `Models.Powers/AmbergrisPower.cs`
